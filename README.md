# SnowSplit

An offline-first, privacy-friendly Android expense & debt splitting app built with Jetpack Compose, interactive physics bubbles, and custom dynamic themes.

## About this project
- **AI-assisted, human-crafted:** Both **SnowSplit** and its companion app **SnowDo's** were built with AI assistance, while still putting a lot of time, design thinking, testing, and personal effort into every detail.
- **Development status:** **SnowDo's** is currently a bit further ahead in features than **SnowSplit**, though both apps are actively maintained and developed side by side.
- **Please respect the project:** This source code is shared openly (GPL-3.0) so you can inspect, build, and contribute—please do **not** simply rebrand or pass the app off as your own work.
- **Bugs & feedback:** Found a bug or have an idea? Feel free to open a **GitHub Issue**!

## Build from source
Prerequisites: **JDK 17** and **Android SDK** (`ANDROID_HOME` configured or opened once in Android Studio).

```bash
# Installable debug APK
./gradlew assembleDebug

# Release APK (unsigned unless you configure a keystore)
./gradlew assembleRelease
```
